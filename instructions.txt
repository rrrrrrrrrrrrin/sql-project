1. In VSC, in the project folder, create file docker-compose.yml
name: SQL-PostgreSQL

services:
  postgres: 
    image: postgres:19beta4-alpine3.24  # postgres image
    container_name: gamestore_db
    restart: always
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: password
      POSTGRES_DB: gamestore
    ports:
      - "5431:5432"

2. In VSC terminal: 
docker compose up -d
docker ps (to list all running docker containers)
docker exec -it gamestore_db sh (to access postgres container's shell)
psql -U postgres (postgres here is POSTGRES_USER from yml file; to connect to postgres using psql)

To exit: 
postgres=# exit (exit postgres shell)
/ # exit (exit docker container)

3.  In shell:
\l или SELECT datname FROM pg_database; (to look up available databases)
CREATE DATABASE name;
DROP DATABASE name;
\c gamestore (to connect to a database; can't drop it when connected to it; gamestore=#)

5. Type localhost:5050 into browser search bar, it will open pgAdmin
Insert email and password from PGADMIN_DEFAULT_EMAIL and PGADMIN_DEFAULT_PASSWORD

Use query tool to insert sql code

6. Load JSON data.
Create db-data folder in project folder.
In docker-compose-with-database-data.yml:
name: SQL-PostgreSQL
