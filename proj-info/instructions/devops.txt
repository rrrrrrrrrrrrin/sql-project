1.1 [requirements.txt is in UTF-16 LE, needs to be in UTF-8:

Format-Hex .\backend\requirements.txt | Select-Object -First 2

Look at the first bytes: FF FE - UTF-16 LE

In root:

# Путь к файлу
$path = ".\backend\requirements.txt"

# Читаем файл в исходной кодировке UTF-16 LE
$content = Get-Content -Path $path -Raw -Encoding Unicode

# Сохраняем в UTF-8 без BOM
$fullPath = (Resolve-Path $path).Path
$utf8 = New-Object System.Text.UTF8Encoding($false)

[System.IO.File]::WriteAllText($fullPath, $content, $utf8)]

2.2 Database tests.
Update database/init.sql:
Add at the beginning:
-- Enable password hashing functions
CREATE EXTENSION IF NOT EXISTS pgcrypto;

We will not use gamestore_db for testing. 
Create a separate PostgreSQL test container:

docker run --name gamestore_test_db `
  -e POSTGRES_USER=postgres `
  -e POSTGRES_PASSWORD=test_password `
  -e POSTGRES_DB=gamestore_test `
  -p 5434:5432 `
  -d postgres:17-alpine


Database: gamestore_test, port: 5434
[Database: gamestore, port: 5433]

Run:
docker exec gamestore_test_db pg_isready -U postgres -d gamestore_test
Expected:
/var/run/postgresql:5432 - accepting connections

Copy init.sql into the test container:
docker cp .\database\init.sql gamestore_test_db:/tmp/init.sql

Execute:
docker exec gamestore_test_db psql -v ON_ERROR_STOP=1 -U postgres -d gamestore_test -f /tmp/init.sql

Verify tables:
docker exec gamestore_test_db psql -U postgres -d gamestore_test -c "\dt"

In backend/tests create: conftest.py, test_database.py

2.3 Start the test container:
docker start gamestore_test_db

Set the connection URL in PowerShell 
(we are in .venv [activated virtual environment]):

Install psycopg2 driver: python -m pip install psycopg2-binary

Add [psycopg2-binary==2.9.13] in backend/requirements.txt. 

$env:TEST_DATABASE_URL = "postgresql+psycopg2://postgres:test_password@localhost:5434/gamestore_test"

Run pytest from the backend directory:
cd backend
python -m pytest -v


We should still get 4 passing tests, 
but now pytest will verify the PostgreSQL connection 
and use the separate test database.
